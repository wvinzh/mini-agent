# 数据分析报告

按以下步骤执行，**不要跳步**：

1. **读取数据**：用 `read_file` 读取用户指定的 CSV 文件；不知道文件名时先用 `list_dir` 查看。
2. **理解字段**：确认每一列的含义、记录条数、时间范围。
3. **计算指标**：所有数字都必须用 `calculator` 计算，**禁止心算**。至少包括：
   - 总量（如总销售额）
   - 平均值
   - 最大/最小值及对应对象
   - 最大项占总量的比例（%）
4. **获取模板**：调用 `read_skill_file("data-report", "template.md")`，严格按模板结构填写，不增删章节。
5. **保存（可选）**：如果用户要求保存，用 `write_file` 写到 `reports/` 目录下，文件名用英文。
6. **回复用户**：输出完整报告正文；若已保存，在末尾注明路径。

## 写作规则
- 数字保留两位小数，金额加单位"元"，比例用百分号。
- 每条"关键发现"都必须引用具体数字，不写空话。
- 发现异常值（明显偏离平均值 50% 以上）要在"异常与风险"中点名。
- 建议要可执行，最多 3 条。
