# 竖屏短剧分镜脚本

## 第一步：先看范例
第一次使用本技能时，先调用 `read_skill_file("short-drama-script", "reference/example.md")`
阅读一集完整范例，模仿它的格式和节奏。

## 硬性规范
- 画幅：竖屏 9:16；单集总时长 **60–90 秒**。
- **黄金 3 秒**：第 1 个镜头必须是冲突/反转/悬念，不能用空镜或慢铺垫。
- 每个镜头 2–6 秒；全集 12–20 个镜头。
- 结尾必须"卡点"：留下悬念或反转，让观众想看下一集。
- 台词口语化，单句不超过 20 字；旁白尽量少。
- 写完后用 `calculator` 把所有镜头时长加总，确认在 60–90 秒内，不符合就调整。

## 输出结构（按顺序，不可缺项）
1. **剧名 / 集数 / 一句话梗概**
2. **人物表**：姓名、身份、外形关键词（用于保持 AI 生成角色一致性）
3. **分镜表**（Markdown 表格，列固定如下）：

| 镜号 | 时长(s) | 景别 | 运镜 | 画面描述 | 台词/音效 | AI 画面提示词(英文) |
|---|---|---|---|---|---|---|

   - 景别只能用：特写 / 近景 / 中景 / 全景 / 远景
   - 运镜只能用：固定 / 推 / 拉 / 摇 / 跟 / 手持
   - AI 提示词：英文，包含"主体 + 动作 + 场景 + 光线 + 风格"，结尾加 `vertical 9:16, cinematic`；
     同一角色每次都使用人物表里相同的外形关键词。
4. **总时长核对**：写出加总算式与结果。
5. **下集钩子**：一句话。
